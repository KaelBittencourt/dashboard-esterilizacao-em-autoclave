# Steriview — Dashboard CME

Dashboard Analítico interativo para gestão e auditoria da Central de Materiais e Esterilização (CME) - Foco em Autoclave.

## Tecnologias

Este projeto foi construído utilizando:
- [Vite](https://vitejs.dev/) e SWC
- [React](https://react.dev/) com TypeScript
- [Tailwind CSS](https://tailwindcss.com/) com shadcn/ui
- [Recharts](https://recharts.org/) para visualizações premium de dados
- Integração em tempo real com Planilhas.

## Executando Localmente

Para rodar o projeto no seu ambiente de desenvolvimento:

1. Clone o repositório
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor:
   ```bash
   npm run dev
   ```

Acesse o endereço local apresentado no terminal para visualizar a interface interativa.

## Histórico
Desenvolvido como solução personalizada *white-label* para modernização de controles internos, auditoria SCIH e gestão de fluxo de materiais e tecidos.
